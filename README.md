# Reypage｜GAS業務自動化

Google スプレッドシート、Gmail、フォーム、ドライブの手作業を、Google Apps Script で自動にします。

## 経歴
- 勤め先の営業組織で約3.5年、社内の業務を自動にするGASを作ってきました。他部署から依頼を受けて仕組みを作り、運用まで担当しました。
- 自分で作った仕組みの一つは約2,700人に使われ、1人1日約1〜2時間（見込み）の事務作業が減りました。

## 頼める仕事の例
- メールやフォームの内容をシートへ転記
- 集計と週次・月次レポート
- 担当者別・取引先別のPDF作成と保存
- 期限や未完了の通知
- 前の担当者が作ったGASの修正

## 料金の目安
- 小さな自動化：最短1日〜・1.5万円〜
- 標準：約1週間〜・5万円〜
- 小さな範囲（シート1つ・処理1つ・通知1つ）、日数は内容が決まった日から数えます

## 進め方
内容を決める、作る、納品、納品後1か月の修正（無料）

Reypage builds Google Apps Script automation for Sheets, Gmail, Forms and Drive.
I built and ran Apps Script tools for about 3.5 years inside a large sales organization. One of them was used by around 2,700 people and reduced each person's workload by an estimated 1 to 2 hours a day.
All 7 sample repositories above use fictional data.
